# Starter Kits

## What this is

Per-capability quick starts — the minimum needed to stand up one capability inside a domain. Where an accelerator packages a whole service, a starter kit is scoped to a single discipline: the smallest working API, event producer, schema contract, MCP server, or agent that conforms to its capability standard.

## Intended kits (add on demand)

One kit per capability, created when a domain first needs it:

`api` · `event` · `data` · `schema` · `semantics` · `knowledge-graph` · `mcp` · `a2a` · `agent` · `security` · `observability` · `infrastructure` · `delivery`

Each kit points back to its standard under `../../capabilities/<capability>/` and drops the smallest conformant starting code into the matching domain folder.

## Governance

Central. A kit is real code that teaches the golden path — hold it to the same bar as production.
