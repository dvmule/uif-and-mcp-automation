# Layout, Composition & Visual Devices

## Grid

12-column grid, proportional margins/gutters (gutters = ¼ of margin size). Applies to portrait, landscape, and square formats alike.

## Principles

- **Intentional whitespace** — generous spacing aids scanning; never cram content.
- **Clear hierarchy** — size, weight, and color work together to guide the eye, not compete.
- **Dynamic but controlled** — energized, never cluttered.
- **Half-and-half** — a reliable default: typography on one half, imagery/waves on the other. Not mandatory, but a good starting pattern when unsure.
- Brand devices (waves, pictograms, icons) are used with purpose, never as decoration for decoration's sake.

## Choosing a visual device — decision tree

```
Is this a signature, big-picture moment?
├── YES → Use a graphic wave
└── NO
    ├── Focused, subject-driven, storytelling?
    │   ├── Concrete scenes/people → Photography
    │   └── Abstract/conceptual ideas → Illustration
    └── Detail- or data-oriented?
        ├── Large concepts/ideas → Line wave
        ├── Quick idea conveyance / organizing info
        │   ├── Literal idea → Icon
        │   └── Larger conceptual idea → Pictogram
```

## Graphic waves (hero-level device)

- Represent the ripple effect of learning. Two approved directions only: **Progress** (left→right) and **Ascend** (bottom→top). Never any other direction, never reversed.
- Wave crest must sit within one half of the layout (first or last half) — never crop away the full crest impression.
- Never: rotate beyond the two orientations, recolor, invent new wave types, use more than one per layout, combine with photography or pictograms/icons on the same artboard, or place type over the crest.

## Line waves (secondary device — use sparingly)

- Three styles: propulsion lines (kinetic energy), simplified waves (steady movement), ripples (360° reverberation).
- Same direction rule as graphic waves (left-to-right or bottom-to-top).
- Approved colors **only**: Pearson Purple `#0D004D`, Amethyst `#512EAB`, Light Purple `#C1BFFF`, White `#FFFFFF` — never accent colors.
- Stroke weight formula: print = layout perimeter (in) ÷ 8 (pt); digital = layout perimeter (px) ÷ 800 (pt). E.g., a 1920×1920 px square (perimeter 7680px) → ~9.6pt stroke.
- Never: fill with an off-background color, use more than one per composition, combine with graphic waves or pictograms, or let it undermine legibility/a photo subject.

## Pictograms & icons

- Pictograms: default Core Purple colorway; at most one accent-colored pictogram per set; use approved light/dark variants; never mix with icons in the same set; never recreate — use the approved library.
- Icons: small accompaniments to copy, not hero illustrations; one color per page/group unless intentionally highlighting one; never mix with pictograms; never vary stroke weight within a group.

## Photography

- Depict Pearson's actual global audience: K–12, Grade School, Early Ed, Higher Ed, College/University, Educators, Professional/Continuing Ed, Government, Workplace, Medical, Trades.
- Rich contrast, authentic environments, natural lighting, real diversity — not staged stock-photo energy.
- Three categories: **Learning** (active learning moments), **Spotlighting** (confident portraits), **Living** (vitality/output of education).
- Wave-effect images (proprietary texture bridging photo + graphic language): no text overlays ever, no color/gradient alterations, and on web use as a hero image or in a designated container — never as a thumbnail or background texture.
- Never: pair an image with a graphic wave on the same artboard, alter/tone/desaturate an image, make an image black-and-white, or crop so tight that context is lost.

## Data visualization layout

See `colors.md` for the actual palette. Layout-specific rules:

- Simplicity first — the goal is a chart a reader can parse in seconds.
- Direct labels beat legends where there's room.
- 1px white stroke between adjacent bars/segments of similar hue so they don't visually merge.
- New categories get a pattern (crosshatch/diagonal lines), never an invented color.
- Minimize non-data ink — no unnecessary borders, backgrounds, or 3D effects.
