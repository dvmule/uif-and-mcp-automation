# whatever the Glue image provided. This file is derived from the actual imports
# in src/, so the package list is accurate, but pinning a version here would mean
# inventing one. Confirm each against the deployed layers, then pin with `==` to
# match stacks/beacon/src/requirements.txt.

# the API degrades rather than failing when a layer is absent.
